# Routine for Mac

Routine is a free Mac app for the few routines that matter to you. When one is due, a reminder stays on screen until you act on it.

This repository only hosts the downloads. The app's source code is private.

## Download

**[Download the latest version](../../releases/latest)**

You need a Mac with macOS Tahoe or later. Apple silicon and Intel are both supported.

## Install

1. Open the download and drag Routine to your Applications folder.
2. Open Routine. When macOS says it can't verify the app, click **Done**.
3. Go to **System Settings › Privacy & Security** and click **Open Anyway**. You only do this once.
4. Open Routine again. A short tour helps you set it up.

## Privacy

Your routines, history and work log stay on your Mac. Routine reads your calendars only to find clashes and never changes them. To find lyrics, it sends the song title and artist to lyrics services. You can turn these off in Settings.
